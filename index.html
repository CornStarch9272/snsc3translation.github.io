Welcome!


After a decade of development, we have finally finished the English translation patch for Summon Night: Swordcraft Story ~Hajimari no Ishi~!


What is covered?


We tried to make this patch as complete as possible. Here's a list of everything we've translated!

  • All Dialogue
  • All Menu UI
  • All Images with text
  • Character Names
  • Location Names
  • Item Names and Descriptions
  • Bestiary Names and Descriptions
  • Minigame Rules
  • Credits
  • Pretty much all Japanese text in the game

What is NOT covered?


Sometimes, due to hardware limitations or other factors there are simply some things we can not accomplish. Here is a list of everything we did not cover.

  • Voice Dubbing
  • Physical Hardware Testing (It may work. We just haven't tested it outside of emulators)

Where to download?


The translation patch can be downloaded from the Download page, or from our Github repository at [link].

You will need to apply the patch to your legally obtained copy of Summon Night: Swordcraft Story ~Hajimari no Ishi~.


What if I find a bug?


We have worked very hard to make sure we haven't introduced any gameplay bugs. We have also proofread the script several times to fix any translation/grammar errors. However, we are still human. It's very possible we have missed some things.

If you find a bug - gameplay, transaltion, or otherwise - we would appreciate it if you left a bug report on the project's Github page at [link].
